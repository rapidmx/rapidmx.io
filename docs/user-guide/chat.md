# Chat

:::note[In early development]
Team chat is not available yet. The Chat plugin (`@rapidmx/chat-plugin`, version 0.1.0) is at an early stage: it
hasn't been published, it has no screens for users, and it can't be installed on a RapidMX server. This page will
describe how to use it once it's released.
:::

Email works well for messages that need a record and a considered reply. It's slower for quick back-and-forth
within a team: a question that needs a one-line answer, a heads-up that a build is broken, a thread of ideas
during a project. Chat is meant for that kind of conversation.

The Chat plugin is planned as a real-time messaging space for teams, in the style of Discord. A team would get its
own channels for different topics, and conversations could branch into threads. Like the other optional features,
it will be a plugin that an administrator turns on (see [Plugins](../administration/plugins.md)).

Until then, use [shared mailboxes](./shared-mailboxes.md) for team conversations, and
[video meetings](./video-meetings.md) for talking live.

## For administrators

There is nothing to install or configure yet. The package hasn't been published to npm, so it can't be added from
the **Plugins** page.
